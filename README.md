# Technical Research Notebook

A version-controlled notebook for AI evaluation research,
Python experiments, and open-source engineering investigations.

## Topics
- AI evaluation
- Experiments
- Bug investigations
- Research note template

## Research principles
1. Separate hypotheses from verified findings.
2. Record exact inputs, outputs, and reproduction steps.
3. Define mathematical symbols and assumptions.
4. Reference source-code paths and tests.
5. Record limitations and unresolved questions.
